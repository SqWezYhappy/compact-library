# Purple Library

Библиотека приложений для Windows 11 в фиолетовом стеклянном стиле. Открывается слева клавишей **Win** или **Ctrl+Alt+Space**, ищет программы из меню «Пуск», держит закреплённые и настраивается под ваши цвета и размеры.

![icon](assets/icon.png)

## Возможности
- Окно слева, прокрутка вниз, по три приложения в ряд, поиск.
- Значок у часов (открыть, настройки, выход), повторный запуск ярлыка тоже открывает окно.
- Настройки: готовые темы, пять цветов (`#RRGGBB`), прозрачность, свечение, скругление, ширина, высота, отступы, размеры иконок, закреплённые приложения, автозапуск.
- **Автообновление** через GitHub Releases.
- Без установки: один `PurpleLibrary.exe`, .NET SDK не нужен.

## Установка
1. Откройте раздел **Releases** и скачайте `PurpleLibrary.exe`.
2. Запустите. Windows может показать предупреждение SmartScreen, так как файл не подписан: «Подробнее» → «Выполнить в любом случае».
3. Настройки хранятся в `%APPDATA%\PurpleLibrary\settings.txt`.

## Автообновление
Раз в 6 часов программа проверяет последний релиз на GitHub. Если версия новее, у значка появляется уведомление, а в **Настройки → О программе** кнопка **Обновить**. Она скачивает новый `PurpleLibrary.exe`, заменяет старый и перезапускает программу. Отключается переключателем «Проверять обновления автоматически».

## Сборка из исходников
Нужна только Windows 10/11. Запустите `build.bat`, результат появится в `bin\PurpleLibrary.exe`. Локальная сборка показывает версию `0.0.0-dev`, обновления в ней отключены, пока репозиторий не подставлен.

## Как выпустить релиз
1. Создайте репозиторий на GitHub и загрузите эти файлы:
   ```
   git init
   git add .
   git commit -m "Purple Library"
   git branch -M main
   git remote add origin https://github.com/ВАШ_ЛОГИН/PurpleLibrary.git
   git push -u origin main
   ```
2. Выпустите версию тегом:
   ```
   git tag v1.0.0
   git push origin v1.0.0
   ```
3. GitHub Actions (`.github/workflows/release.yml`) соберёт `PurpleLibrary.exe`, подставит номер версии и имя репозитория и создаст Release. Следующие версии выпускаются так же: `v1.0.1`, `v1.1.0` и так далее. Установленные программы сами предложат обновление.
